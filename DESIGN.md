# jvdm-ui visual direction

## Identity

jvdm-ui is a generative parametric identity. One theme seed controls rhythm, type, radius, density and motion. The documentation site makes that mechanism visible through real components rather than decorative mockups.

The visual language is a measured instrument: editorial whitespace, hard alignment, compact metadata and surfaces that feel assembled from a reliable grid. It is technical without pretending to be a terminal.

## Composition

- The first viewport uses a left-aligned split composition. The message owns the left side; a live component specimen owns the right side.
- Sections are separated by generous rhythm, not by repeated cards or decorative section numbers.
- The catalog is a field of working examples. Cards are used only where a component group needs a surface boundary.
- The theme playground is the main proof moment. Editing JSON changes the surrounding surface, so the interaction demonstrates the product claim.

## Type and shape

- Headlines use a compact system sans with tight tracking and a strong weight step.
- Labels use the existing mono scale only for code, token names and measurements.
- The site uses the existing radius scale, with `md` as the dominant container shape and `xs` for compact controls.
- Motion is restrained and functional: content settles into place, controls respond on press, and seeded theme changes transition without spectacle.

## Color

The default preset remains achromatic. Identity comes from typography, rhythm, scale and surface contrast. Semantic status colors stay semantic and are never used as decoration.

## Motion

The authored moment is the live theme transformation. Entry reveals are short, once-only and removable under reduced motion. Press feedback uses transform only and stays below 160ms.

## Copy

The site speaks plainly to developers. It leads with the enforced rule, then proves that consumers still own the values. It makes no adoption, benchmark or customer claims that are not in the product record.
